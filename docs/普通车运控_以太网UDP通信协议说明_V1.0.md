# 1\. 通信架构

本项目中，上位机/路径规划程序通过以太网向 STM32 运控板下发车辆控制命令。STM32 接收 UDP 报文后解析 26 字节控制帧，写入内部车辆控制结构体，再由 20 ms 周期任务通过 CAN 控制 RT49 驱动、EPS 转向和 SEB 制动。

| **控制链路**                               | **说明**                                 |
| -------------------------------------- | -------------------------------------- |
| 上位机/路径规划程序 -\> UDP -\> STM32           | 推荐使用。UDP payload 直接放 26 字节 cmd\_\_ 报文。 |
| RK3588/PC -\> USART1 -\> STM32         | 保留原串口 26 字节控制入口。                       |
| 遥控器 -\> SBUS转UART -\> USART3 -\> STM32 | 保留遥控器入口；遥控器有效时优先级最高。                   |
| STM32 -\> CAN1/CAN2 -\> 执行机构           | CAN1 控制 EPS；CAN2 控制 RT49 与 SEB。        |

|                                                                                                       |
| ----------------------------------------------------------------------------------------------------- |
| **优先级说明：**遥控器有效时会在 CAN 下发前覆盖以太网/串口上位机命令。因此做以太网联调时，如发现 UDP 命令已收到但车辆不执行，请先确认遥控器是否正在有效接入或 CH5 是否处于未使能状态。 |

# 3\. UDP payload：26 字节控制帧格式

所有多字节字段均采用大端序 Big-Endian。除特别说明外，字段按有符号整数解析。校验和为前 22 字节逐字节累加后的 uint32，大端放在最后 4 字节。

| **字节偏移** | **长度** | **字段**           | **类型**    | **说明**                                                          |
| -------- | ------ | ---------------- | --------- | --------------------------------------------------------------- |
| 0\~4     | 5      | Header           | ASCII     | 固定为 63 6D 64 5F 5F，即字符串 cmd\_\_                                 |
| 5        | 1      | Version          | uint8     | 固定建议 0x01                                                       |
| 6        | 1      | Mode             | uint8     | 0x01=自动模式；0x02=调试模式；0x00=不使能                                    |
| 7        | 1      | Flags            | uint8     | bit0 急停；bit1 EPS回中；bit2 SEB自动刹车；bit3 SEB对中                      |
| 8        | 1      | EnableMask       | uint8     | bit0/0x01=RT49；bit1/0x02=EPS；bit2/0x04=SEB，可按位组合                |
| 9\~12    | 4      | Param1: v\_raw   | int32 BE  | 速度字段。v\_raw = 目标速度(m/s) × 10000；支持负数表示后退                        |
| 13\~16   | 4      | Param2: eps\_raw | int32 BE  | 转向字段。当前以太网 26 字节接口沿用原串口协议：eps\_raw = 目标转角(°) × 10000；支持负数表示反向转角 |
| 17       | 1      | SEB Mode         | uint8     | 0=不控制；1=压力模式；2=行程模式；3=对中；4=自动刹车                                 |
| 18\~19   | 2      | SEB Value        | int16 BE  | 压力模式：MPa×100；行程模式：mm×10                                         |
| 20       | 1      | Light/Reserved   | uint8     | 灯光/预留，当前可置 0x00                                                 |
| 21       | 1      | Counter          | uint8     | 序号/计数，可 0\~255 循环递增；当前控制计算不依赖该字段，但参与校验                          |
| 22\~25   | 4      | Checksum         | uint32 BE | sum(byte0\~byte21) & 0xFFFFFFFF                                 |

# 4\. 字段取值与换算关系

| **对象**  | **字段/取值**            | **换算说明**                             | **示例**                                                              |
| ------- | -------------------- | ------------------------------------ | ------------------------------------------------------------------- |
| RT49 速度 | Param1 / v\_raw      | v\_raw = 速度(m/s) × 10000             | 0.2 m/s -\> 2000 -\> 00 00 07 D0；-0.2 m/s -\> -2000 -\> FF FF F8 30 |
| EPS 转向  | Param2 / eps\_raw    | eps\_raw = 转角(°) × 10000；正负方向由实车标定确定 | 30° -\> 300000 -\> 00 04 93 E0；-30° -\> FF FB 6C 20                 |
| SEB 压力  | SEB Mode=1，SEB Value | SEB Value = 压力(MPa) × 100            | 0.2 MPa -\> 20 -\> 00 14；0.5 MPa -\> 50 -\> 00 32                   |
| SEB 行程  | SEB Mode=2，SEB Value | SEB Value = 行程(mm) × 10              | 0 mm -\> 0 -\> 00 00；10 mm -\> 100 -\> 00 64                        |
| 使能掩码    | EnableMask           | 0x01 RT49，0x02 EPS，0x04 SEB，可相加组合    | 0x03=RT49+EPS；0x07=RT49+EPS+SEB                                     |

|                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------- |
| **EPS 注意：**当前网络接口与原 26 字节串口接口保持一致，上位机发送的是“角度×10000”的应用层字段，不直接发送 EPS CAN raw。若后续底层改成直接接收 0.1°/count 的 raw 值，需要双方同步更新本协议。 |

| **⚠️ 本地勘误（2026-08-05，待与 STM32 侧确认）：**实车联调发现 STM32 实际按 **`转角(°) / 0.1° × 10000`（即 `×100000`）** 解释 eps_raw，与本节“×10000”不符；按本节 `×10000` 实现会导致转向失灵（字段值小 10 倍）。详见 `docs/steering_eps_scale_troubleshooting.md`。在固件侧确认前，请以 `×100000` 为准。 |

# 5\. 校验和计算

校验和只计算 byte0\~byte21，不包含最后 4 字节校验和本身。计算结果按 uint32 大端写入 byte22\~byte25。

```python
def calc_checksum(frame22: bytes) -> int:
    # frame22 为前 22 字节，即 byte0~byte21
    return sum(frame22) & 0xFFFFFFFF
```

# 7\. 上位机发送示例代码

路径规划程序可按以下方式生成报文。实际工程中建议把速度、转角、制动压力等封装为函数，并按固定周期发送。

```python
import socket
import struct

STM32_IP = "192.168.1.50"
STM32_PORT = 5000

def build_cmd(enable_mask, v_mps=0.0, eps_deg=0.0,
              flags=0, seb_mode=0, seb_value_raw=0,
              light=0, counter=0):
    frame = bytearray()
    frame += b"cmd__"                     # byte0~4
    frame += bytes([0x01, 0x01, flags & 0xFF, enable_mask & 0xFF])
    frame += struct.pack(">i", int(round(v_mps * 10000.0)))
    frame += struct.pack(">i", int(round(eps_deg * 10000.0)))
    frame += bytes([seb_mode & 0xFF])
    frame += struct.pack(">h", int(seb_value_raw))
    frame += bytes([light & 0xFF, counter & 0xFF])
    checksum = sum(frame) & 0xFFFFFFFF
    frame += struct.pack(">I", checksum)
    assert len(frame) == 26
    return bytes(frame)

sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)

# 示例：RT49 + EPS 联合控制，前进 0.2m/s，右转 30°
cmd = build_cmd(enable_mask=0x03, v_mps=0.2, eps_deg=30.0, counter=1)
sock.sendto(cmd, (STM32_IP, STM32_PORT))

# 示例：SEB 压力刹车 0.2MPa
# seb_value_raw = 0.2 * 100 = 20
cmd = build_cmd(enable_mask=0x07, v_mps=0.0, eps_deg=0.0,
                seb_mode=1, seb_value_raw=20, counter=2)
sock.sendto(cmd, (STM32_IP, STM32_PORT))
```

# 8\. 联调测试建议

1.  PC 网卡设置静态 IP：192.168.1.100，子网掩码 255.255.255.0。

2.  PC 与 STM32 运控板 RJ45 网口直连或接入同一交换机。

3.  上位机先以 50 ms 周期发送 RT49 停止 + EPS 回中报文，确认底层无异常动作。

4.  再发送单项指令：RT49 小速度、EPS 小角度、SEB 小压力，使用 CAN 分析仪确认对应 CAN ID 与数据变化。

5.  实车测试前先悬空或限速，最大速度建议从 0.1\~0.2 m/s 开始。

6.  如 UDP 命令已发出但 CAN 无变化，优先检查：IP/端口、校验和、遥控器是否接管、STM32 是否超时。

# 10\. 常见问题排查

| **现象**                            | **可能原因**                      | **处理建议**                                                        |
| --------------------------------- | ----------------------------- | --------------------------------------------------------------- |
| PC ping 不通                        | 当前固件未实现 ICMP Echo Reply       | 不以 ping 作为唯一判断；用 UDP 发送和调试变量/抓包确认                               |
| dbg\_eth\_rx\_udp\_cnt 不增加        | IP、端口、网线、网卡网段不对，或 ARP 未完成     | 确认 PC IP=192.168.1.100，同网段；目标 192.168.1.50:5000；抓包看是否有 UDP 发出   |
| dbg\_eth\_rx\_cmd\_cnt 增加但 ok 不增加 | 报文头或校验和错误                     | 确认 Header=cmd\_\_，payload 至少 26 字节，Checksum=sum(byte0\~21)      |
| ok 增加但车辆不动作                       | 未使能、模式不对、遥控器优先级覆盖、CAN 执行机构未连接 | Mode 用 0x01 或 0x02；EnableMask 置对应 bit；关闭遥控器或确认 CH5 状态；看 CAN 分析仪 |
| 车辆动作后很快停止                         | 发送周期过低或停止发送，触发 500 ms 超时保护    | 上位机保持 20\~50 ms 周期发送有效命令                                        |
| 转向/速度方向相反                         | 车辆执行机构方向定义与上位机坐标系相反           | 联调确认正负号；必要时在上位机侧取反或底层配置取反                                       |

# 附录 A：建议上位机控制策略

路径规划工程师建议每个控制周期发送一帧“联合控制”报文，而不是分别发送速度帧、转向帧和制动帧。联合控制时，EnableMask 可置为 0x03 或 0x07，速度、转角和 SEB 字段在同一帧中同步更新，便于底层按同一时刻的控制目标执行。

| **控制场景**   | **建议 EnableMask** | **速度字段**  | **转向字段**          | **SEB字段**               |
| ---------- | ----------------- | --------- | ----------------- | ----------------------- |
| 正常行驶       | 0x03              | 填写目标速度    | 填写目标转角            | SEB Mode=0              |
| 带制动控制行驶/停车 | 0x07              | 刹车时速度建议置0 | 按需保持或回中           | SEB Mode=1，Value=压力×100 |
| 安全停止       | 0x03 或 0x07       | 0         | 0，或 Flags bit1 置位 | 按需释放或刹车                 |
