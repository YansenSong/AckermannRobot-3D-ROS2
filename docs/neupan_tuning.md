# NeuPAN 参数调优指南：按机器人尺度归一化

## 核心思想

NeuPAN 的 MPC 代价函数由四项组成，每一项都有不同的物理单位：

```
Cost = q_s²·||s - ref_s||²  +  p_u²·||v - ref_v||²  +  0.5·bk·||s - s_nom||²  -  η·d
       位置追踪 (m²)              速度追踪 (m/s)²             近端正则 (m²)             安全距离 (m)
```

**问题**：如果直接比较这些异构量的数值，调参会变成"猜数字"。正确的做法是引入机器人特征尺度做归一化。

## 特征尺度

| 符号 | 含义 | 本项目实车 | 大型汽车示例 |
|------|------|:---:|:---:|
| L₀ | 特征长度 (车长) | 1.40 m | 5.0 m |
| v₀ | 巡航速度 | 1.0 m/s | 10.0 m/s |
| ψ_max | 最大转向角 | 0.52 rad | 0.6 rad |
| R_min | 最小转弯半径 | 由轴距与最大转角计算（当前约 1.68 m） | 6.0 m |

## 归一化框架

### 1. 位置追踪权重 `q_s`

**有效代价** = q_s² × (Δx)²。要判断一个位置偏差是否"大"，应该除以车长：

```
归一化偏差 = Δx / L₀
```

设计原则：**当 Δx/L₀ ≈ 0.3（偏离 30% 车身长度）时，代价应该达到 ~0.1**，确保 MPC 不会忽略这个偏差。

```
q_s² × (0.3·L₀)² ≈ 0.1
→ q_s ≈ 0.33 / (0.3·L₀) ≈ 1.1 / L₀
```

| 机器人 | L₀ | 建议 q_s | 有效代价 (Δx=0.2m) |
|--------|:--:|:--------:|:-------------------:|
| 本项目实车 | 1.4m | **待实车调优** | 以实测跟踪效果为准 |
| 大型汽车 | 5.0m | 0.15 | 0.0225 × 0.04 = 0.0009 |

**结论**：小机器人需要更大的 `q_s`，因为同样的 0.2m 偏差对小机器人来说占比更大。

### 2. 控制代价 `p_u`

**注意**：`p_u` 只惩罚线速度偏差 `||v_x - ref_v||²`，**不惩罚转向角**。转向的约束完全靠 `max_acce` 中的转向角速度限制。

```
p_u² × Δv² — 归一化: Δv / v₀
```

设计原则：速度波动 ±30% 时产生中等代价 (~0.05)：

```
p_u² × (0.3·v₀)² ≈ 0.05
→ p_u ≈ 0.22 / (0.3·v₀) ≈ 0.75 / v₀
```

| 机器人 | v₀ | 建议 p_u |
|--------|:--:|:--------:|
| 本项目 | 1.0 m/s | **0.3** |
| 大型汽车 | 10.0 m/s | 0.5 |

### 3. 安全距离权重 `eta`

避障代价 = η × d，其中 d ∈ [d_min, d_max]。

**关键洞察**：d_max 和 L₀ 的比例决定了障碍物的"威胁感"。

```
d_max / L₀ > 1  → 障碍物很远就开始躲 → 路径宽大
d_max / L₀ < 0.5 → 障碍物很近才躲 → 路径贴着走
```

设计原则：在 d_max 处的避障收益不应完全碾压跟踪需求：

```
η × d_max ≈ q_s² × (0.5·L₀)²   (两者在同一数量级)
→ η ≈ (q_s² × 0.25 × L₀²) / d_max
```

对于本项目当前初值 (L₀=1.4, d_max=1.0, q_s=0.5)：

```
η ≈ (0.25 × 0.25 × 1.96) / 1.0 ≈ 0.12  ← 但这是理论下界
实际取 η = 3~5，因为避障仍需要主导地位
```

| 机器人 | d_max | q_s | 建议 η |
|--------|:-----:|:---:|:------:|
| 本项目实车 | 1.0m (0.7 L₀) | 0.5（初值） | **待实车调优** |
| 大型汽车 (开阔室外) | 2.0m (0.4 L₀) | 0.15 | **10~15** |

### 4. 近端正则 `bk`

SCP 迭代中，`0.5 × bk × ||s - s_nom||²` 保证解不偏离线性化点太远。

约束：**bk 的有效力必须小于 q_s²，否则解被锁死在线性化点上**：

```
0.5 × bk < q_s²
→ bk < 2 × q_s²
```

| q_s | q_s² | bk 上限 |
|:---:|:----:|:-------:|
| 0.15 | 0.0225 | 0.045 |
| 0.5 | 0.25 | 0.5 |

**当前 bk=0.1**，在小 q_s 时是束缚（0.1 > 0.045），在大 q_s 时是安全的（0.1 < 0.5）。无需改。

### 5. 安全距离上下界

```
d_min ≈ 0.07 × L₀   (约 7% 车长，紧急刹车距离)
d_max ≈ 0.7 × L₀    (约 70% 车长，开始关注的距离)
```

| 机器人 | L₀ | d_min | d_max |
|--------|:--:|:-----:|:-----:|
| 本项目实车 | 1.4m | 0.10m | 1.0m |

## 本项目参数推导全过程

### 问题诊断

| 参数 | 原值 | 有效代价 | 物理意义 |
|------|:---:|:---:|------|
| q_s | 0.15 | 0.0225 × Δx² | 小机器人 0.2m 偏差代价仅 0.0009 — 被忽略 |
| p_u | 0.5 | 0.25 × Δv² | 线速度波动被强约束 |
| eta | 15 | 15d ∈ [0.75, 7.5] | 0.5m 处的障碍物代价 7.5，碾压追踪（8300:1） |

**结果**：MPC 花 99.99% 的精力躲避 0.5m 外的障碍物，基本不关心是否偏离参考路径 → 转弯半径远大于 1.05m。

### 最终方案

当前实车初值按 L₀=1.4m、v₀=1.0m/s 设置，仍需低速实车验证：

```yaml
adjust:
  q_s: 0.5     # Δx/L₀=0.3 → 代价 0.011，MPC 开始"在乎"偏离
  p_u: 0.3     # Δv/v₀=0.3 → 代价 0.008，不打压速度调整
  eta: 4.0     # 避障:追踪 ≈ 2.0:0.011 ≈ 180:1 (原来 8300:1)
  d_max: 1.0   # ~0.7 L₀
  d_min: 0.10  # ~0.07 L₀
```

这些数值只是初始配置，不代表已经在当前实车上验证通过。

## 调参流程 (通用)

### Step 1: 确定特征尺度

```
L₀ = 机器人长度
v₀ = 巡航速度
R_min = 最小转弯半径
```

### Step 2: 用公式算初值

```
q_s ≈ 1.1 / L₀
p_u ≈ 0.75 / v₀
η  ≈ (q_s² × 0.25 × L₀²) / d_max  × (5~20)  # 根据环境决定倍数因子
d_max ≈ 0.7 × L₀
d_min ≈ 0.07 × L₀
```

### Step 3: 验证标准

| 现象 | 诊断 | 调整 |
|------|------|------|
| 转弯半径 > 参考路径 | 追踪太弱 | ↑ q_s 或 ↓ eta |
| 弯道出口震荡 | 过激追踪 | ↓ q_s 或 ↑ p_u |
| 不避让障碍物 | 避障太弱 | ↑ eta |
| 远远绕开障碍物 | 避障太强 | ↓ eta |
| 路径发抖 | 对定位噪声过敏 | ↓ q_s |
| SCP 不收敛 | 近端束缚不够 | ↑ bk 或 ↓ q_s |

### Step 4: 边界情况测试

- 无障碍物直线：路径应平滑、速度稳定
- 90° 转弯：转弯半径应接近 R_min
- 窄通道 (车宽 + 0.3m)：应缓慢通过，不碰撞
- 动态障碍物：应在 d_min 距离内急停
