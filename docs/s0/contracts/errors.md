# 错误与确认语义（当前实现）

| 状态 | 含义 | 客户端处理 |
|---|---|---|
| HTTP 400 | 参数/请求结构无效 | 修正请求，不自动重试 |
| HTTP 401/403 | 未登录/角色、CSRF 或机器人作用域不允许 | 停止写入并提示权限 |
| HTTP 404 | 任务/地图/点位等不存在 | 重新读取权威状态 |
| HTTP 409 | revision、幂等键内容或机器人运行条件冲突 | 显示机器人拒绝理由，检查状态后决定重试 |
| HTTP 503 | 桥接器或执行器不可用 | 保留原 `Idempotency-Key` 查询/重试，不生成新执行 |
| HTTP 202 + `pending` | 平台记录指令但未拿到端侧 ACK | 查询 `command_id`，不能显示“已执行” |
| HTTP 202 + `accepted` | 机器人已确认接收/处理指令 | 继续看任务状态/事件直到终态 |
| 机器人 ACK `ok:false` | 端侧明确拒绝，包括停车、低电、充电、定位/地图 stale、区域停车和严重故障 | 显示 `error` 原文并保持安全操作可用 |
| 机器人 ACK `status:unknown` | 崩溃后持久化命令声明存在但结果未知 | 查询机器人状态和事件；相同 ID 不再执行第二次 |

当前 HTTP 错误体、机器人 ACK 和前端展示尚未全部收敛为统一机器可读 `error_code`；S0-05/S0-13 仍需后续实施。不能把 HTTP 202 当做任务终态。
